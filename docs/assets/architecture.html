内容安全

  • 你只改主稿；程序只写自己生成的文件
  • 保存前检查版本，别处改过就提示冲突
  • 删除先进回收站

外出时

  • 写作、AI 对话、发布照常
  • 建提醒照常，到点照发
  • 转写连不上家里就直接失败，不排队

密钥与访问

  • 密钥只存 macOS 钥匙串，不回显
  • 家里服务只在 Tailscale 里监听，要带访问密钥
  • 提醒只发给自己验证过的邮箱

运行形态

  • Beer：一个 tgz，装进 DSH Desktop
  • 家里：macOS LaunchDaemon
  • 提醒：Workers Free 就够用
